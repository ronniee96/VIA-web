## 📌 Executive Overview

**Vidarbha Industrial Associates (VIA)** has been at the forefront of heavy industrial maintenance since **1997**. Headquartered in **Chandrapur, Maharashtra**—the heart of India's thermal coal and heavy manufacturing corridor—VIA provides turnkey **ultra-high pressure (UHP) hydro-jetting up to 1100 BAR (16,000 PSI)**, chemical descaling, non-destructive testing (NDT), and boiler/condenser turnarounds.

Over **28+ years of continuous service**, VIA has executed critical turnarounds for India's largest power utilities, integrated steel plants, cement works, and chemical complexes.

## 🛠️ Architecture & Tech Stack

This website is engineered with a **high-performance, zero-dependency static web architecture** optimized for instant loading, sub-second TTFB, and zero-maintenance hosting on Vercel:

- **Markup:** Semantic HTML5 with complete OpenGraph, Schema.org, and meta tags.
- **Styling:** Tailwind CSS (via CDN) paired with custom CSS hardware-accelerated animations (`marquee`, `flip-card`, `hud-pulse`).
- **Typography:** `Montserrat` (Bold industrial display titles) + `Inter` (high-legibility body) + `JetBrains Mono` (engineering telemetry).
- **Interactive Simulator:** Plain HTML5 `<canvas>` with 60 FPS touch and cursor mask erasure that interactively wipes away simulated boiler scale to reveal 4K condenser equipment beneath.
- **Instant Inquiry Engine:** Client-side WhatsApp lead generation linking directly to `+91 9422837904` with structured plant specifications.
- **Zero Secrets / Zero Backend:** 100% serverless, zero API keys required, zero build step needed.

## 🚀 Local Preview

Run a local preview server with Python:

```bash
# Clone the repository
git clone https://github.com/ronniee96/VIA-web.git
cd VIA-web

# Start instant HTTP server
python3 -m http.server 8080
```

Open your browser at [http://localhost:8080](http://localhost:8080).

## 🌐 One-Click Deployment to Vercel

### Option A: Vercel CLI
```bash
npx vercel --prod
```

### Option B: Vercel Dashboard
1. Go to [vercel.com/new](https://vercel.com/new).
2. Select **`ronniee96/VIA-web`**.
3. Framework Preset: **Other** (Zero-Config).
4. Root Directory: `./` (Leave Build & Output commands blank).
5. Click **Deploy**.
